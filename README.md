## 为什么你会停不下来

这把工具和其他 AI 写作助手有一个本质区别：**它不满足于「能用」，它追求「每个输出都值得收藏」。**

### 你生成的每一篇作文，都是一份精读材料

AI 写完作文后，不会随便挑几个词敷衍你。它会逐句扫描全文，只挑**真正值得讲的东西**：

- 六级/考研/雅思级别的高级词汇（`exacerbate`、`formidable`、`imperative`）
- 地道的高级短语搭配（`hinge on`、`grapple with`、`in the wake of`）
- 熟词的生僻义项（`address` 不只是"地址"，更是"解决"）
- 学术写作连接词（`consequently`、`nevertheless`、`albeit`）

而 `important`、`good`、`bad`、`make`、`do` 这些词——**一个都不会出现**。

### 每个例句，本身就是一节微型写作课

你随手查一个词，AI 返回的不是那种"Hello, how are you"级别的例句，而是——

> *The proliferation of misinformation exacerbated social divisions, necessitating a paradigm shift in regulatory frameworks.*
> 虚假信息的泛滥加剧了社会分裂，亟需监管框架的范式转变。

一条例句里藏着三四个高级词汇。你本来只想查 `exacerbate`，结果看到了 `proliferation`、`paradigm shift`、`regulatory framework`——**你忍不住又去查了这些词**。

### 然后你就进去了

这就是这个工具最"可怕"的地方：

```
查 exacerbate → 例句里看到 proliferation → 查 proliferation
→ 例句里看到 ubiquitous → 查 ubiquitous
→ 例句里看到 discourse → 查 discourse
→ ...
```

**每一次查词都是一次高质量的输入**。你不是在背单词书，你是在真实、有难度、有语境的内容里自然遇到这些词。每个例句都在告诉你：这个词在六级作文里可以这么用。

## 功能

### ✍️ 智能作文生成
- 输入 CET-6 作文开头句，AI 即时生成**三段式高分范文**（150–200 词）
- 严格遵循 Introduction → Body → Conclusion 结构
- 还原真题试卷格式，身临其境的备考体验
- 词数统计，直观对照评分标准

### 🌐 全文翻译
- 精准中文译文，段落一一对应
- 理解范文逻辑，同步提升阅读与翻译能力

### 📚 深度词汇讲解——核心亮点
- 自动甄选作文中**每一个值得讲解的词和短语**，拒绝简单词
- 每个词包含：音标 · 词性 · 释义 · 文中用法 · 3 个高难度例句（含翻译）
- **例句本身就是学习材料**：每个例句含其他高级词汇与复杂句式，可直接用于作文
- 一键收藏到词汇本

### 🔍 智能查词——真正的"黑洞"入口
- 输入任意英文单词，秒得完整词典信息
- **自动识别变形**：搜 `automating` → 提示「是 automate 的现在分词」并展示原形
- 展示：音标 · 词性 · 多释义 · 其他变形 · 3 个**作文级例句**（含翻译）
- 每个例句都刻意包含六级词汇和好用的句型——**你会发现你一直在搜下一个词**
- 一键收藏到词汇本

### ⭐ 双收藏系统
- **作文收藏**：保存范文 + 译文 + 完整词汇数据，支持查看回填
- **词汇收藏**：独立的词汇本，卡片式展示，含完整例句
- 均支持**置顶 / 取消置顶 / 删除**（带确认）
- 数据保存于浏览器 localStorage，关机不丢失

### 🎲 AI 实时推荐题目
- 每次打开或点击「换一批」，DeepSeek 实时生成 5 个 CET-6 风格开头句
- 覆盖科技、教育、环境、社会、文化、健康等热点话题

## 核心理念

> **高质量输入 → 忍不住继续查 → 更多高质量输入**

这不是一个"输入题目、复制粘贴、关掉页面"的工具。它是设计来让你**沉浸其中**的——每一篇作文值得精读，每一个词条值得收藏，每一条例句都是一次学习的机会。

你打开它本来只想写一篇作文，半小时后你发现自己在查第十五个单词——**这就是它正确的打开方式**。

## 快速开始

### 1. 获取 API Key

前往 [DeepSeek 开放平台](https://platform.deepseek.com/) 注册并获取 API Key。

### 2. 打开应用

双击 `index.html`，在页面中输入你的 DeepSeek API Key（以 `sk-` 开头），点击保存。

### 3. 开始使用

- **生成作文**：点击推荐题目或手动输入开头句，点击「生成作文」
- **查词**：在查词框输入任意英文单词——然后顺着例句里不认识的好词继续查下去
- **收藏管理**：点击页面底部「词汇收藏」或「作文收藏」按钮

> 💡 无需安装任何依赖，无需服务器，纯前端运行。

## 设计原则

- **零依赖**：不引入任何第三方库或框架，降低维护成本
- **离线友好**：生成内容可收藏后离线查看，数据本地持久化

- **移动适配**：响应式布局，手机端同样可用
